# Call of Duty Source

This repository stores the data obtained by the [ate47/atian-cod-tools](https://github.com/ate47/atian-cod-tools) fastfile handlers. This repository is here to test these handlers with various games.

## Paths

| Game                  | Path      |
| --------------------- | --------- |
| Black Ops 4           | `bo4`     |
| Black Ops Cold War    | `cw`      |
| Vanguard              | `vg`      |
| Modern Warfare II     | `mwii`    |
| Modern Warfare II SP  | `mwiisp`  |
| Modern Warfare III    | `mwiii`   |
| Modern Warfare III SP | `mwiiisp` |
