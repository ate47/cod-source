//		cg_shrink: reduce lod distance. If existing lod distance is lower, keep that

//		ng_replace: replace existing values with new one (PS5, Scarlett & PC only)
//		ng_shrink: reduce lod distance. If existing lod distance is lower, keep that
//		ng_grow: increase lod distance. If existing lod distance is heigher, keep that
//
// example: cg_replace,foliage_tree_oak_01_efm_siege,0,,200,400,800,1600,
